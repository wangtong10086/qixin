# 栖信接管记录（2026-10-22）

栖信已接管管理界面、CLI、通知岛和状态展示。定制 `com.xiaomi.xmsf` 运行时已安装，兼容钩子并入同一个 APK；原 `io.github.magisk317.mipush` 模块已卸载。HMS Core 已卸载，飞书离线推送调查暂停。最终版本进入 24 小时观察，尚未完成长期稳定性验收。

## 已完成

- 原 APK、CE/DE 数据、数据库、通知设置、系统覆盖和 Vector 配置均已备份并校验哈希。通过普通卸载/安装完成签名切换，恢复数据并修正新 UID 的属主；没有修改系统签名校验或 PackageManager 数据文件。
- 原 50 条应用配置记录迁移到数据库 v10，注册材料和历史负载由迁移测试比对指纹。当前 46 个应用有注册记录；注册数量可随实际运行变化。
- 新运行时为 release 非调试版本，系统特权身份生效。重启后小米连接恢复，系统通知适配和通知身份适配均报告已加载；FCM 仍使用现有 Google 服务。
- 旧模块的 Vector 作用域已迁移至运行时。系统兼容钩子与运行时均关闭遥测。发布构建曾出现 R8 改名导致 AbstractMethodError，已补齐编译期 API 依赖及回调保留规则；修正版重启后适配正常，不保留失败版本运行。
- 因 UID 变化恢复了原 3 个有效通知渠道及其重要性、声音、振动等设置，并读取核对。不是通过重置全部通知设置完成迁移。
- GUI / root CLI 共用本地管理服务，读取连接、注册、事件和逐应用配置，不依赖网络管理接口。迁移后的同步通过运行时 Binder，不直接读它的数据库。
- 小米推送配置可选择注册允许/询问/拒绝、阻止推送、注册提醒及点击回退。声音与振动入口进入 Android 通知设置，不显示无效开关。
- 消息、常驻服务、持续任务分开存储和显示；v2rayNG 等前台服务的持续更新只覆盖状态，不淹没消息历史。取消通知后清理对应状态。
- 栖信通知岛支持展开、进度、原始 PendingIntent 和操作按钮，息屏隐藏。关闭旧运行时的通知岛及焦点通知，避免重复展示。
- HMS 的新增栖序规则和 deviceidle 白名单已撤回，安装包已卸载，临时 HMS 注册入口移除。不清除飞书数据，不继续发送测试消息。
